# Code of Conduct

Contributors and maintainers are expected to participate respectfully. Harassment, discriminatory attacks, threats, and unsolicited publication of private information are not acceptable.

For disagreements, focus on the code, evidence, and design trade-offs. Maintainers may moderate issues and pull requests or restrict participation to protect a constructive environment.

For conduct reports, use GitHub's repository owner contact/profile mechanisms rather than posting sensitive information publicly. This document applies to project issues, pull requests, and project-maintained discussions.
