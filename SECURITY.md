# Security policy

Roentgen is a development preview. It does not currently promise supported security patch timelines or production-hardening.

Please **do not publish vulnerability details in public issues**. If the GitHub repository has private vulnerability reporting enabled, use **Security → Report a vulnerability**. Otherwise contact the repository maintainer privately through their GitHub profile. Include affected revision, proof of concept, impact and safe reproduction steps. Do not submit real credentials or private save data.

Third-party vulnerabilities in .NET or NuGet packages should be handled by updating supported packages and reviewing upstream advisories.
