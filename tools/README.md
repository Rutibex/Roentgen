# Development tools

Repository-hosted authoring and validation tools:

- AssetLab — procedural mesh and material recipes.
- WorldLab — terrain and regional topology.
- StructureLab — settlements, structures, interiors and repair.
- CreatureLab — generated humanoids, creatures, skeletons, skinning, poses and target parts.

QuestLab, BalanceLab, FactionLab, AgentLab, ItemLab, CombatLab, and Seed Inspector remain separate development assemblies. Tool assemblies remain separate from the shipping executable.

## Roentgen.CombatLab

Headless Phase 10 real-time combat diagnostics, deterministic duels, large seed soaks, armor inspection and canonical state export.

## Roentgen.BalanceLab

Phase 12 attribute, skill, XP, perk-graph, build-viability, and deterministic progression-soak tool.

## Roentgen.ItemLab

Phase 13 generated-item, assembly, loot, inventory, economy, and arbitrage analysis tool.

## Roentgen.QuestLab

Phase 16 kernel authoring, deterministic slot binding, fact and knowledge tracing, dialogue preview, route simulation, recovery injection, six-build solving, replay, export, and repetition analysis.
