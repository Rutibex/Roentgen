# Attributes, Skills, and Derived Statistics

Attributes use explicit stable enum values and remain from 1 to 10. Character creation starts all seven at 4 and requires exactly fourteen allocated points before background adjustments.

Skills use the canonical fourteen-skill list. Starting values are calculated from data-driven primary and optional secondary attribute bindings. Three specializations add 15. Skill purchase costs are 1 point through 50, 2 points from 51–75, and 3 points from 76–100.

Derived statistics are pure, integer calculations. Fractional per-second rates use deterministic accumulators. Maximum health changes preserve missing health instead of granting a free heal. Focus capacity changes preserve spent and reserved Focus.
