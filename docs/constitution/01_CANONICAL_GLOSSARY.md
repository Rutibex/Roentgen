# Canonical Glossary

This glossary prevents terminology drift. Code identifiers may use PascalCase equivalents, but player-facing names must use the canonical form unless an approved ADR changes them.

## Product and mode names

- **Roentgen** — Game title.
- **Roentgen Focus** — Full-pause tactical targeting and action-queue system.
- **Focus** — Resource spent to queue actions in Roentgen Focus.
- **Campaign Seed** — Root deterministic identity for a campaign.
- **World State Delta** — Persisted change to regenerated base content.
- **Diagnostic Overlay** — Visual layer used by Roentgen Focus and analysis systems.

## Generation language

- **Recipe** — Compact instructions that reconstruct an asset or content unit.
- **Kernel** — Authored semantic structure whose roles are bound to generated facts.
- **Domain Seed** — Stable seed derived for one named responsibility.
- **Provenance** — Record of the seeds, generator versions, bindings, validation, and repairs that produced an object.
- **Validator** — Detects violations of declared invariants.
- **Repair Stage** — Bounded mutation intended to satisfy failed invariants.
- **Reservation** — Space, role, or object guaranteed for campaign or quest use before decorative generation.
- **Strategic Simulation** — Abstract simulation of distant factions and settlements.
- **Reduced Simulation** — Lightweight simulation of unloaded but locally relevant actors.
- **Full Simulation** — Detailed active simulation near the player.

## Avoided or forbidden player-facing aliases

The following should not appear as Roentgen system names:

- VATS or V.A.T.S.
- Pip-Boy.
- SPECIAL or S.P.E.C.I.A.L.
- Vault.
- Vault-Tec.
- Nuka-anything.
- Stimpak.
- RadAway.
- Brotherhood of Steel.
- Enclave.
- Super Mutant.
- Deathclaw.
- Caps as the universal currency.

Generic words may appear in ordinary English when not used as imitation branding. For example, a literal bottle cap may exist as junk, but “caps” must not be the canonical world currency.
