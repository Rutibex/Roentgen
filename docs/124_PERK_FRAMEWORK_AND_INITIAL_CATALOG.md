# Perk Framework and Initial Catalog

The general perk catalog replaces the isolated Phase 11 Focus list. Requirements support level, attribute, skill, prior perk, background, trait, faction training, and discovery. A validator detects missing effect registrations, impossible references, cycles, empty perks, and a catalog that falls below the 70% behavior/option target.

The initial forty perks cover ballistics, directed energy, demolitions, melee, unarmed, Roentgen Focus, stealth/security, engineering/science, medicine/fieldcraft, influence, and commerce. Perk effects are typed capability records rather than scattered string-name checks in gameplay systems.
