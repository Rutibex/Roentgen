# Character Creation, Backgrounds, and Traits

Character creation is a draft transaction. It supports attribute allocation, three specialized skills, one background, two compatible traits, personal-history tags, an equipment grant manifest, review, and one-time finalization.

The optional questionnaire only creates an editable recommendation. It never bypasses ordinary validation.

Phase 12 includes eight backgrounds and sixteen traits. Backgrounds normally exchange +1 and -1 attributes, add skill context, provide knowledge/dialogue tags, and produce a Phase 13 equipment grant. Traits contain both benefits and drawbacks and are validated for incompatibility.
