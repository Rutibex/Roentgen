# QuestLab

QuestLab is the Phase 16 deterministic narrative inspection tool.

## Commands

- `list-kernels`
- `generate` / `bind`
- `inspect-slots`
- `inspect-facts`
- `inspect-knowledge`
- `simulate-route`
- `simulate-all-routes`
- `preview-dialogue`
- `kill-role-actor`
- `destroy-required-item`
- `block-location`
- `expire-deadline`
- `validate`
- `repair`
- `solve`
- `export`
- `replay`
- `compare-seeds`
- `analyze-repetition`

Each generated quest exposes its stable ID, kernel version, bound slots, binding reasons, validation history, repair history, and checksum.
